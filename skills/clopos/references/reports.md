# Hesabatlar və uzlaşdırma

## Vaxt və əhatə

Sorğunun dövrünü tarixlərlə qeyd et. Brend/filial, əməliyyat günü, terminal, şöbə, satış üsulu, mənbə və çek statusu nəticəni dəyişir. Kassanın günü gecəyarısı başlamaya bilər: açılış 06:00 olduqda gecə satışı əvvəlki əməliyyat gününə düşə bilər. Müqayisədə eyni vaxt əsasını istifadə et. [Açılış saatı](https://az.help.clopos.com/az/article/kassanin-acilis-saati-ssnvjy/)

Yalnız hesabat istənirsə uyğunsuzluğu düzəltmək üçün resept, şöbə və maliyyə qeydlərini dəyişmə.

## Bölməni seç

| Sual | Başlanğıc bölmə |
| --- | --- |
| Məhsul üzrə miqdar, satış, maya | Statistika → Hesabatlar → Məhsullar |
| Mətbəx/bar və digər şöbələr | Statistika → Hesabatlar → Şöbələr |
| Nağd/kart/digər ödəmə üsulları | Statistika → Hesabatlar → Ödənişlər |
| Qaytarılan məhsullar | Statistika → Hesabatlar → Geri Qaytarılma |
| Çekin tərkibi və hərəkətləri | Satış → Çeklər, konkret ID |
| Anbar dəyişikliklərinin səbəbi | İnventar → Məhsul hərəkətləri |

[Məhsullar](https://az.help.clopos.com/az/article/statistikamehsullar-1k6mvbk/), [şöbələr](https://az.help.clopos.com/az/article/statistikasobeler-746dq4/), [ödənişlər](https://az.help.clopos.com/az/article/statistikaodenisler-12zmc6k/), [qaytarmalar](https://az.help.clopos.com/az/article/statistika-geri-qaytarilma-k6rlql/)

Məhsul detalındakı modifikator, çıxarılan ehtiyat və qapalı çek görünüşləri silinməni araşdırmağa kömək edir. Satış sayını inqrediyent çıxışı ilə qarışdırma. Ödəniş hesabatında əməkdaş filtri çeki bağlayanı göstərə bilər; bunu çek sahibinə görə hesabat adlandırma.

## Cəmləri tutuşdur

UI/eksport yekununu sətir cəmləri ilə müqayisə et. Yuvarlaqlaşdırma, ikram, endirim, xidmət haqqı, vergi, qaytarma və açıq/qapalı çek əhatəsini araşdır. Şöbə cəmi ümumi satışa bərabər gəlmirsə şöbəsiz məhsul/setləri yoxla; öz qərarınla Mətbəxə aid etmə.

Səhifələmədə bütün uyğun sətirləri al. Görünən ekran cəmini tam hesabat kimi vermə. Sütun seçimi eksporta təsir edə bilər; lazım olan ID/sütunları əvvəl aç. [Eksport](https://az.help.clopos.com/az/article/melumatlarin-eksport-edilmesi-157r4ey/)

Başda dövr və filtrləri, sonra nəticə və uyğunsuzluqların sübutunu göstər. Öz hesablamanı sistemin hazır göstəricisindən ayır. Fayl istənirsə uyğun cədvəl alətini işlət, ID/ad/vahid/miqdar/məbləği ehtiyaca görə saxla; xam eksportu yekun hesablamayla qarışdırma.
